# 🛠️ QRaw

QRaw platform - a collection of useful tools for everyday digital tasks. Focused on user experience and made with ❤️!

## 🚀 Features

### QRGenerator

Simple and efficient QR code generator.

## 📦 Getting Started

1. Clone the repository and install the dependencies.

    ```bash
    git clone https://github.com/wojnet/qraw.git
    npm install
    ```

2. Run the development server on port 3000

    ```bash
    npm run dev
    ```
